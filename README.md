### Data
All gene count data (all.gene_counts.xlsx) are available in the data folder of this repository. The raw sequencing data have been deposited in the Gene Expression Omnibus (GEO) under accession number **GSE302064**.

### Code
The code used to perform differential gene expression analysis ```dge-analysis.R```, Hallmark Gene Set Enrichment Analysis ```gsea-hallmark.R```, and generate the figures ```all-figures.R``` is available in the code folder of this repository.
